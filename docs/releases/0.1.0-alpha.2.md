# NeonOmen 0.1.0-alpha.2

Development release for World of Warcraft Forever (Interface 16001).

Changes since 0.1.0-alpha.1:

- Keep long meter titles clear of the numeric column headings.
- Avoid rebuilding an unchanged bar gradient during refreshes.
- Use the NeonOmen name in the minimap tooltip.
- Keep the meter position under addon control to avoid conflicts with the
  client's saved window layout after a reload.
- Add an in-game settings screenshot to the English and Chinese README files.
  The screenshot shows the built-in example data, not a live encounter.

The settings screen, example data, some live combat and physical controller
navigation have been tested in the Forever client. Restricted threat data
still needs further live verification.
